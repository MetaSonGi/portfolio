# Hyogi Son — LEGO 놀이동산 포트폴리오

손효기(Hyogi Son) 개인 포트폴리오 사이트. **Three.js로 만든 3D 레고 놀이동산** — 미니피겨 캐릭터로 공원을 돌아다니며 포트폴리오를 탐색합니다.

- **기술**: HTML / CSS / JavaScript / Three.js (CDN)
- **배포**: GitHub Pages + Vercel (GitHub push 시 자동 재배포)

## 게임 플레이

- 🖱️ **클릭으로 이동** — 바닥을 클릭하면 캐릭터가 걸어갑니다
- ⌨️ **WASD / 방향키** — 직접 조종
- 🎢 **놀이기구 탑승** — 5개 구역(🗼 자이로드롭=기술 / 🎠 회전목마=소개 / 🎡 관람차=경력 / 🏴‍☠️ 바이킹=프로젝트 / 🚗 범퍼카=연락)에 들어가면 설명 패널이 열리고, **타기!** 버튼으로 직접 탑승할 수 있습니다
- 🧭 **상단 메뉴** — 버튼을 누르면 캐릭터가 해당 놀이기구로 걸어갑니다
- 🚪 **구역 이탈** — 구역을 벗어나면 패널이 자동으로 닫힙니다
- 🧍 **NPC** — 다른 미니피겨들이 공원을 돌아다닙니다

## 월드 구성

- 레고 베이스플레이트(스터드 포함), HYOGI LAND 입구 아치, 매표소, 중앙 분수 광장
- 5개 놀이기구 (회전목마·관람차·자이로드롭·바이킹·범퍼카) — 전부 실제 작동
- 가로등, 벤치, 화단, 나무, 구름, 별이 있는 밤하늘 놀이동산
